# Optional Tip Jar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a single, repeatable, optional $2.99 tip via StoreKit 2, surfaced as one row in Settings, with no persisted state and no network calls of the app's own.

**Architecture:** A small `TipJar` class in the `DidI` app target wraps StoreKit 2's async purchase flow for one consumable product. `SettingsView` gets one new "Support" section with a button that shows the StoreKit-provided localized price and triggers the purchase. A `.storekit` configuration file lets the flow be tested in the simulator without App Store Connect.

**Tech Stack:** Swift, StoreKit 2 (`StoreKit` framework, `Product`/`Transaction` async APIs), SwiftUI. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-27-tip-jar-design.md`

## Global Constraints

- No backend, no account, no network calls of the app's own — StoreKit talks to Apple directly, which does not violate this (per spec "Constraints").
- iOS 17+ minimum — StoreKit 2 async/await APIs only, no `SKPaymentQueue`.
- App-only feature: `DidICore`, `DidIWidget`, `DidIWatch` are untouched.
- Product ID: `com.dihnatovich.didi.tip.small`, Consumable, $2.99, repeatable.
- Nothing about a tip is persisted to the App Group `Store` — no entitlement tracking, no "has tipped" flag.
- All user-facing strings go through `Copy.swift` (`DidICore/Sources/DidICore/Copy.swift`), with pl/ru translations added alongside — this is an existing repo convention (`CLAUDE.md` "Conventions"), not new scope.

### Task 1: `TipJar` purchase wrapper

**Files:**

- Modify: `DidI/DidIApp.swift:18-19` (start the transaction-updates listener alongside the existing `StoreChange.startListening()` / `WatchSync.shared.start()` calls)

**Interfaces:**
- Produces: `@Observable final class TipJar` with:
  - `static let shared = TipJar()`
  - `private(set) var product: Product?`
  - `func loadProduct() async` — fetches and stores the one `Product`
  - `func purchase() async throws -> Bool` — `true` on success, `false` on user cancellation, throws on any other failure
  - `func startListeningForTransactionUpdates()` — call once at launch; runs an unstructured `Task` loop over `Transaction.updates` that verifies and finishes any transaction not yet finished

No other task depends on internals beyond this surface.

- [ ] **Step 1: Write `TipJar.swift`**

```swift
import StoreKit

/// One consumable tip, no entitlement, nothing persisted. This class exists
/// purely to hide StoreKit's verification/finish bookkeeping from the UI —
/// `SettingsView` only ever sees `product` and calls `purchase()`.
@Observable
final class TipJar {
    static let shared = TipJar()

    static let productID = "com.dihnatovich.didi.tip.small"

    private(set) var product: Product?

    private init() {}

    func loadProduct() async {
        product = try? await Product.products(for: [Self.productID]).first
    }

    /// Returns `true` on a completed purchase, `false` if the user cancelled.
    /// Any other outcome (verification failure, pending/ask-to-buy, StoreKit
    /// error) throws so the caller can show an error.
    func purchase() async throws -> Bool {
        guard let product else {
            await loadProduct()
            guard let product else { throw TipJarError.productUnavailable }
            return try await purchase(product)
        }
        return try await purchase(product)
    }

    private func purchase(_ product: Product) async throws -> Bool {
        let result = try await product.purchase()
        switch result {
        case .success(let verification):
            let transaction = try verify(verification)
            await transaction.finish()
            return true
        case .userCancelled:
            return false
        case .pending:
            return false
        @unknown default:
            return false
        }
    }

    /// Started once at launch. Catches transactions that finished outside a
    /// direct `purchase()` call in this session — e.g. the app was killed
    /// between StoreKit completing the purchase and `finish()` being called.
    /// Without this, an unfinished transaction is redelivered by StoreKit on
    /// every future launch.
    func startListeningForTransactionUpdates() {
        Task.detached {
            for await update in Transaction.updates {
                if let transaction = try? self.verify(update) {
                    await transaction.finish()
                }
            }
        }
    }

    private func verify<T>(_ result: VerificationResult<T>) throws -> T {
        switch result {
        case .unverified:
            throw TipJarError.unverifiedTransaction
        case .verified(let value):
            return value
        }
    }
}

enum TipJarError: Error {
    case productUnavailable
    case unverifiedTransaction
}
```
