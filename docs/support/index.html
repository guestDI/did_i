Did I? Support

For help, bug reports, or accessibility feedback, email ignatovich.dm@gmail.com.

Useful checks

  • If a widget looks stale, open Did I? once and confirm the app and widget are using the same selected item.
  • If “When I come home” does not expire a confirmation, check Location Services and allow the requested permission for Did I?.
  • If the Watch display is stale, open Did I? on both the iPhone and paired Apple Watch.

Privacy

Did I? has no account, ads, analytics, or developer server. Read the privacy policy.

Did I? is a memory aid, not a safety system. Always verify anything important directly.
